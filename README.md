# ANIMEMISO

แพ็กเกจเว็บไซต์พร้อมไฟล์ API สำหรับนำไป Deploy บน Vercel

## ไฟล์ในโปรเจกต์

- `index.html` — หน้าเว็บ ANIMEMISO เดิม (ถอดส่วนโฆษณาและธีมเทศกาลแล้ว)
- `api/download.js` — API ฝั่งเซิร์ฟเวอร์ เชื่อมต่อแพ็กเกจ `@coflyn/scrapr`
- `package.json` — dependencies ของเซิร์ฟเวอร์
- `vercel.json` — การตั้งค่า Vercel

## Deploy

1. แตกไฟล์ ZIP
2. นำโฟลเดอร์โปรเจกต์ขึ้น GitHub
3. เข้า Vercel แล้ว Import Git Repository
4. Deploy โดยใช้ Root Directory เป็นโฟลเดอร์โปรเจกต์นี้
5. ทดสอบหน้าเว็บ และลองส่งลิงก์ที่รองรับผ่านระบบ

ไม่ต้องตั้งค่า `API_URL` ในหน้าเว็บ เพราะใช้ `/api/download` อยู่แล้ว

## ข้อจำกัดที่ควรรู้

- API ใช้บริการและตัวแยกข้อมูลจากแพ็กเกจภายนอก ความพร้อมใช้งานขึ้นอยู่กับการเปลี่ยนแปลงของแพลตฟอร์มต้นทางและข้อจำกัดของผู้ให้บริการ
- บางเว็บไซต์อาจไม่รองรับบางรูปแบบ หรืออาจปฏิเสธคำขอเป็นครั้งคราว
- ใช้เฉพาะสื่อที่คุณเป็นเจ้าของหรือได้รับอนุญาตให้ดาวน์โหลด และปฏิบัติตามเงื่อนไขของเว็บไซต์ต้นทาง
- ระบบ Premium/รหัสแอดมินใน HTML เวอร์ชันนี้ยังเก็บข้อมูลในเบราว์เซอร์ของอุปกรณ์ ไม่ใช่ระบบสมาชิกส่วนกลางที่ปลอดภัย และยังไม่ควรใช้รับชำระเงินจริง
- รายการเพลงเริ่มต้นถูกตั้งเป็นว่าง เพราะไม่ได้รับไฟล์เพลงต้นฉบับมาด้วย ผู้ใช้สามารถเพิ่มไฟล์เสียงของตนเองในเครื่องเล่นได้

## Firebase Authentication (เข้าสู่ระบบ / สมัครสมาชิก)

หน้าเว็บมีระบบสมัครสมาชิกและเข้าสู่ระบบด้วยอีเมล/รหัสผ่านผ่าน Firebase Authentication พร้อมลืมรหัสผ่านและออกจากระบบ โดยใช้ Firebase project `animemiso` ตามค่าที่เจ้าของเว็บให้มา

ก่อนใช้งานจริง ให้ตั้งค่าใน Firebase Console:
1. เปิด **Authentication → Sign-in method** แล้วเปิดผู้ให้บริการ **Email/Password**
2. ไปที่ **Authentication → Settings → Authorized domains** และเพิ่ม `flukh1001-ctrl.github.io` หากยังไม่มี
3. Deploy เว็บไซต์ใหม่ แล้วทดสอบสมัครสมาชิกและเข้าสู่ระบบด้วยอีเมลของตนเอง

หมายเหตุ: Firebase config และ Web API key ที่อยู่ในหน้าเว็บเป็นค่าที่เปิดเผยได้ตามรูปแบบการใช้งาน Firebase Web SDK ไม่ใช่รหัสผ่านแอดมิน แต่ต้องตั้งค่า Security Rules ให้เหมาะสมก่อนเก็บข้อมูลส่วนตัวหรือข้อมูลสมาชิกใน Firestore/Storage ระบบนี้ยืนยันตัวตนด้วย Firebase Auth เท่านั้น ยังไม่ได้สร้างฐานข้อมูลโปรไฟล์สมาชิกเพิ่มเติม

มีการเพิ่มหน้าประมวลผลสั้น ๆ ตอนสลับแท็บดาวน์โหลด/แปลงเสียง พร้อมเอฟเฟกต์เปลี่ยนหน้าแบบ fade เพื่อให้การเปลี่ยนหน้าไม่แข็ง
